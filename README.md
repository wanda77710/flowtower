# FlowTower 物流塔台

一個平台串起「下單 → 撿貨扣帳 → 交車 → 配送 → 簽收」的完整物流流程，並用像素風控制塔即時呈現。

> ⚠ Demo 版本，所有資料皆為虛構假資料。

## 模組
| 模組 | 功能 |
|---|---|
| OMS 下單 | 建單、訂單變更紀錄、要求出車／到貨時間 |
| WMS 倉庫 | 撿貨任務、撿貨確認、扣帳、交車掃碼 |
| TMS 調度 | 派車、併單（同廠同時段）、車趟與續點 |
| 司機手機版 | 點擊回報：交車 → 出發 → 哨口 → 碼頭 → 完成，異常通報，出廠補登 |
| 異常／缺車 | 異常通報與處理、缺車通報與原因分類 |
| 車輛資源 | 各庫房車隊、跨倉支援調度 |
| 專案管理平台 | 運輸團隊專案規劃、任務、核准層級 |
| 控制塔 | 像素風即時看板：T−15／T−5／T0／ETA／+30 警示 |

## 技術
- 前端：靜態網頁（GitHub Pages）
- 資料庫：Supabase（PostgreSQL + Realtime），結構見 `supabase/schema.sql`
